# 15:00 마감추천 전략 P7 모델 승격 게이트

## 결정

뉴스·공시 Feature와 통계·ML 모델을 추천 점수에 바로 연결하지 않는다. 현재 프로젝트에는 모델의
표본 외 개선과 실제 체결 순수익을 검증할 입력이 부족하다. 기존 `RULE_BASED_V8_BASELINE`을 기준선으로
유지한다.

## 자동 확인 조건

- 공식 시간순 OOS 검증 준비
- 최근 전략 성과 감시 준비 및 비악화 상태
- 비용을 반영한 공식 모의 주문·체결 순수익
- 시점별 시장 지수와 유효기간이 있는 업종 이력
- 공개 시각·최초 수신 시각·정정 이력이 보존된 뉴스·공시

통계 모델은 이벤트 데이터 조건을 제외한 항목을 확인한다. 이벤트 모델은 모든 항목을 확인한다.
현재는 공식 모의체결 원장, 시장·업종 원시 자료, 사건 데이터가 없으므로 두 모델 모두 `BLOCKED`다.

## 화면

고급 마감추천의 공식 전진 전략 검증 영역에 각 준비 조건의 충족 여부와 필요한 데이터가 표시된다.
준비 조건이 모두 충족되더라도 상태는 `READY_FOR_EXPERIMENT`이며 운영 추천 승격을 의미하지 않는다.

## 모델 실험 원칙

1. 예측 목표는 비용 반영 체결 기준으로 정의한다.
2. 학습·검증 기간을 시간순으로 분리한다.
3. 규칙 기반 기준선과 같은 후보·시각·비용 조건으로 비교한다.
4. 실패한 실험과 설정도 보존한다.
5. 독립 검증과 공식 전진 표본에서 개선이 재현되기 전에는 운영에 연결하지 않는다.

## 제외 범위

- 뉴스 감성 점수 임의 생성
- 과거 사건 원문 없이 종목 가격으로 뉴스 원인 추정
- 현재 표본을 학습과 검증에 동시에 사용하는 ML
- 검증 전 확률·기대수익 표시
- 실제 주문 연동

P7은 모델을 추가한 단계가 아니라, 근거 없는 모델이 운영 추천에 섞이지 않도록 승격 조건을 코드와
화면에 고정한 단계다.
