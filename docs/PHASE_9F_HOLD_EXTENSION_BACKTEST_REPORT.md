# Phase 9F 보유 연장 전략 백테스트 완료 보고

## 목적

장마감 추천 종목을 다음날 단순 매도했을 때와 목표 도달 이후 추세가 유지될 때 더 보유했을 때의 결과를 비교할 수 있도록 백테스트 응답에 청산 전략별 요약을 추가했다.

## 추가된 전략

- 다음날 시가 매도: 다음 거래일 첫 5분봉 시가 기준 수익률
- 다음날 종가 매도: 다음 거래일 마지막 5분봉 종가 기준 수익률
- 목표/손절 우선 매도: 목표가 또는 손절가 중 먼저 도달한 조건으로 청산
- 목표 후 VWAP 이탈 매도: 목표 도달 후 누적 VWAP 아래로 종가가 내려가면 청산
- 목표 후 20봉선 이탈 매도: 목표 도달 후 다음날 5분봉 20봉 이동평균을 이탈하면 청산
- 추세 양호 시 보유 연장: 목표 도달 후 VWAP, 20봉선, 고점 대비 되돌림 조건이 무너지기 전까지 보유

## 보수적 체결 가정

한 5분봉 안에서 목표가와 손절가가 동시에 도달한 경우 실제 선후관계를 알 수 없으므로 손절 청산으로 계산한다. 해당 건수는 `ambiguousCount`로 별도 표시한다.

## Backend 변경

- `OvernightBacktestResponse`에 `strategySummaries` 필드 추가
- `OvernightExitStrategySummary` DTO 추가
- `OvernightBacktestService`에 청산 전략별 시뮬레이션과 요약 계산 추가

## Frontend 변경

- 백테스트 결과 화면에 `매도 전략 비교` 패널 추가
- 전략별 표본 수, 승률, 평균 수익률, 평균 낙폭, 목표 도달률, 손절 도달률, 동시 도달 건수 표시

## 검증 관점

- 기존 백테스트 정합성 검사는 그대로 유지된다.
- 전략 비교는 정합성 검사를 통과한 별도 데이터가 아니라 같은 백테스트 표본을 다른 청산 규칙으로 재계산한 결과다.
- 현재 MA20 추적 전략은 다음날 장중 5분봉이 20개 이상 쌓인 이후부터 이탈 판단을 수행한다.
