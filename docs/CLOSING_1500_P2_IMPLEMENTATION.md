# 15:00 마감추천 전략 P2 분석

## 구현 범위

- 공식 멱등키로 생성된 `FORWARD` 실행만 전략 통계에 포함한다.
- 익일 관측 상태가 `COMPLETED`이고 계산 버전이 현재 버전인 표본만 사용한다.
- 추천점수를 10점 구간으로 묶어 목표 도달률과 95% Wilson 구간을 계산한다.
- 후보 출처와 탐지 유형별 표본 수, 목표 도달률, 평균 종가 수익률을 제공한다.
- 갭 하락, 종가 손실, 손절선 도달, 목표·손절 동시 도달, -3% 이하 낙폭을 관측 패턴으로 집계한다.
- 고급 마감추천 화면에서 최근 90일 결과를 표시한다.

## 해석 제한

- 30건 미만은 탐색 표본 경고를 표시한다.
- 목표수익률이 여러 개면 점수 구간 직접 비교 경고를 표시한다.
- 손실 패턴은 서로 중복될 수 있으며 손실의 인과관계를 의미하지 않는다.
- 수동 `REPLAY`, 진행 중 관측, 데이터 불완전 관측은 제외한다.
- 실제 주문 체결과 비용을 반영한 순손익 통계가 아니다.
- 목표 도달률과 수익률은 현재 운영 성과 원장의 신호가격 기준 시장 관측이다.

## API

```text
GET /api/v1/closing-recommendations/strategy-analytics
GET /api/v1/closing-recommendations/strategy-analytics?from=2026-06-01&to=2026-09-22
```

분석 기간은 최대 730일이다.

## 검증 방법

1. 수동 재생 run을 추가해도 표본 수가 변하지 않아야 한다.
2. `IN_PROGRESS`, `DATA_INCOMPLETE` 성과는 표본에서 제외되어야 한다.
3. 같은 점수 구간의 목표 도달 건수와 도달률이 일치해야 한다.
4. 표본이 적을수록 95% 구간이 넓어야 한다.
5. 목표수익률 설정이 섞이면 경고가 표시되어야 한다.
6. 손실 패턴 합계는 중복 가능하므로 전체 표본 수와 같을 필요가 없다.
