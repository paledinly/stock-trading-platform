# Phase 9G 추천 알고리즘 튜닝 및 비교 리포트 완료 보고

## 목적

장마감 추천의 운영 기본 전략을 감으로 고르지 않고, 같은 기간과 같은 후보 제한에서 여러 추천 알고리즘 후보를 비교할 수 있도록 백테스트 리포트를 확장했다.

## 비교 대상

- 기존 탐지 점수: 실시간 레이더 탐지 점수와 원본 기회/위험 점수를 중심으로 정렬
- 마감 점수: 장마감 추천 전용 점수에서 이동평균선을 제외한 기준
- 마감 점수 + 이평선: Phase 9D에서 만든 현재 운영 후보
- 보수형 이평선: 최소 기회점수를 높이고 최대 위험점수를 낮춘 방어적 후보

## 비교 지표

- 추천 표본 수
- 완료 건수
- 데이터 누락 건수
- 신뢰도
- 시가 승률
- 종가 승률
- 평균 시가 수익률
- 평균 종가 수익률
- 평균 최고 수익률
- 평균 최대 낙폭
- 목표 도달률
- 손절 도달률
- 손익비
- 고유 종목 수
- 날짜 편중도
- 운영 기본값 후보 여부

## Backend 변경

- `OvernightBacktestResponse`에 `algorithmSummaries` 필드 추가
- `RecommendationAlgorithmSummary` DTO 추가
- `OvernightBacktestService`에서 알고리즘 후보별 가상 추천과 성과 요약 계산 추가
- 표본 수에 따라 `LOW`, `MEDIUM`, `HIGH` 신뢰도 산정
- 신뢰도, 평균 종가 수익률, 종가 승률을 기준으로 운영 기본값 후보 표시

## Frontend 변경

- 오버나잇 백테스트 화면에 `추천 알고리즘 비교` 패널 추가
- 알고리즘별 신뢰도, 완료/누락, 종가 승률, 평균 수익률, 낙폭, 손익비, 종목 수, 날짜 편중도 표시
- 운영 기본값 후보를 시각적으로 구분

## 해석 기준

신뢰도가 낮은 결과는 방향성 참고용으로만 봐야 한다. 최소 20건 이상이면 후보 비교가 가능하고, 50건 이상부터 운영 기본값 판단에 더 적합하다.

평균 종가 수익률만 높고 날짜 편중도가 높은 전략은 특정 날짜 운에 의해 좋아 보일 수 있다. 운영 기본값은 평균 수익률, 승률, 최대 낙폭, 손익비, 표본 수를 함께 봐야 한다.

## 남은 개선 여지

- 알고리즘 비교 결과 저장 테이블
- 기간별 비교 리포트 누적
- 목표/손절/점수 기준 자동 그리드 서치
- 추천 알고리즘별 실제 다음날 보유 연장 전략까지 결합한 통합 리포트
