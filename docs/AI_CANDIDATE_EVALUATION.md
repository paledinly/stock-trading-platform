# AI 후보 평가 (설계, 사전 등록)

상태: **설계 고정(2026-11-18), 구현 전.** 결정과 이유는 [ADR-014](decisions/ADR-014-AI-CANDIDATE-EVALUATION.md). 기록 시작일은 구현 배포 후 첫 거래일이며 CHANGELOG에 적는다.

프로그램이 정한 후보 명단을 ChatGPT가 종목별로 평가한다. 장 마감 뒤 같은 명단의 다른 선택 방법과 비교해 채점한다. 매매 신호가 아니고, 운영 마감 추천·정밀 구독·실주문에 영향을 주지 않는다. 기존 [AI 장전 계획](AI_PREMARKET.md)(ChatGPT가 종목을 직접 찾는 방식)은 그대로 두고 따로 센다.

이 문서의 정의·임계값·판정 기준은 첫 기록 전에 커밋한다. 기록 중에는 바꾸지 않는다. 바꾸면 버전(`ai-candidate-v2` …)을 올리고 처음부터 따로 센다.

## 질문

1. **고르기:** AI가 A등급을 준 종목이 같은 명단 평균보다 나은가? 단순 규칙으로 고른 것보다도 나은가?
2. **걸러내기:** AI가 회피(AVOID)로 표시한 종목이 같은 명단 평균보다 나쁜가?
3. (나중 단계) **매도 기준:** AI가 정한 손절·목표가 고정 기본값보다 나은가? 일봉으로는 손절과 목표 중 무엇이 먼저 닿았는지 알 수 없어서, 실시간 감시에 연결한 뒤에 판정한다. v1은 기록만 한다.

## 1. 후보 명단

- 대상 거래일 d의 [장 전 변동성 명단](decisions/ADR-013-VOLATILITY-SUBSCRIPTION-UNIVERSE.md)(`VolatilityUniverse`, d 이전 일봉만 사용)을 변동성 순서대로 놓고 **상위 40종목**을 쓴다. 오늘 상승률 순위표 종목은 장 시작 전에 알 수 없어서 넣지 않는다.
- 명단을 만든 시각, 종목 순서, 명단 식별값(코드 목록 해시 `poolId`)을 저장한다. AI 응답은 같은 `poolId`일 때만 받는다.
- 명단은 d 전날 18:30(수정주가 일봉) 이후 확정된다. 카드는 해외 지수가 들어온 뒤(07:50 수집)부터 만든다.

## 2. 평가 카드

모든 값은 d 이전 거래일까지의 확정 데이터다. 카드마다 데이터 기준일을 적는다. 09:00 이후 시세는 넣지 않는다.

### 시장 공통 (맨 위 한 번)

| 항목 | 출처 |
| --- | --- |
| S&P500·나스닥·다우·SOX·VIX 전일 등락, 원/달러, EWY | `overseas_daily` |
| 코스피·코스닥 전일·5일·20일 등락 | `market_index_daily` |
| 전일 상승·하락 종목 비율(평균 거래대금 10억 이상 보통주) | `daily_adjusted_candle` |

### 종목별 (40장)

| 구분 | 항목 | 출처 |
| --- | --- | --- |
| 기본 | 코드, 이름, 시장, 업종(중분류, 없으면 생략) | `stock`, `sector_code` |
| 명단 | 변동성 순위, 20일 일간 등락 표준편차 | 명단 계산 |
| 가격 | 전일·5일·20일·60일 등락, 60일 고점·저점 대비, 연속 상승·하락 일수 | `daily_adjusted_candle` |
| 변동 | 최근 20일 +10% 이상·−10% 이하 일수 | 같음 |
| 거래 | 전일 거래대금, 20일 평균 대비 배수, 5일 평균 대비 배수 | 같음 |
| 전일 모양 | 시가 대비 종가, 종가 위치((종가−저가)/(고가−저가)), 상한가 마감 여부 | 같음 |
| 수급 | 외국인·기관·개인 순매수 금액 전일·5일 합 | `investor_daily_flow` |
| 공시 | 최근 5거래일 공시 제목과 접수일(최대 5건) | `dart_filing`. 접수 시각은 없다 |

넣지 않는 것: 뉴스 본문(수집 안 함), 이 프로그램의 다른 점수(정밀 점수·ML 점수, 검증 안 됨), d 당일 데이터.

## 3. AI 응답 규격 `ai-candidate-v1`

프롬프트는 카드 위에 붙는 고정 지시문 `ai-candidate-v1.prompt.md`(구현 때 추가)이다. 응답은 JSON 하나다.

| 칸 | 필수 | 규칙 |
| --- | --- | --- |
| `schemaVersion` | ✓ | `ai-candidate-v1` |
| `targetDate`, `poolId` | ✓ | 카드에 적힌 값과 같아야 한다 |
| `analyzedAt` | | 시간대 포함 시각. 지금보다 5분 넘게 미래면 거부 |
| `model.name`, `model.version`, `model.promptVersion` | ✓ (version은 경고) | |
| `market.outlook` | ✓ | BULLISH / NEUTRAL / BEARISH |
| `evaluations[]` | ✓ | **명단 40종목 모두 한 번씩.** 빠지거나 명단 밖 종목이 있으면 거부 |
| `evaluations[].grade` | ✓ | A / B / C / AVOID. **A는 0~5개.** 넘으면 거부 |
| `evaluations[].rubric` | ✓ | `catalyst`, `flow`, `trend`, `overheat`, `disclosureRisk` 각 0~2 정수 |
| `evaluations[].riskFlags[]` | | `DILUTION`(증자), `CB_BW`, `AUDIT`, `MANAGEMENT_CHANGE`, `OVERHEATED`, `THIN_LIQUIDITY`, `LITIGATION`, `OTHER` |
| `evaluations[].reasons[]` | ✓ | 1~3개 문장 |
| `evaluations[].entry.type` | A·B는 ✓ | `OPEN`(시가), `BREAKOUT_15M`(15분 시가 범위 고가 돌파), `VWAP_RECLAIM`(VWAP 회복), `NONE` |
| `evaluations[].exit` | A·B는 ✓ | `stopPct` 0.8~8, `targetPct` 1~20 또는 null, `timeExit` `CLOSE` / `NEXT_OPEN` |
| `evaluations[].confidence` | ✓ | 0~100 정수 |
| `evaluations[].sources[]` | | AI가 카드 밖 정보(검색)를 썼으면 출처·게시 시각. 미래 시각이면 거부 |

- 카드 밖 정보를 쓴 종목은 `usedExternalInfo`로 표시해 따로 나눠 본다.
- 매수·매도 가격은 원본 JSON에만 남는다. v1 채점은 시가→종가로 한다.

## 4. 저장과 집계 대상

- 장 시작(09:00, 특별 개장일은 그 시각) 전에 저장된 판만 집계한다.
- **같은 날 처음 저장된 정상 판이 집계 판이다.** 이후 판은 "재실행"으로 저장해 등급 일관성만 본다. 결과가 마음에 들 때까지 다시 묻는 것을 막는 규칙이다. 기존 AI 장전 계획(마지막 판)과 다르다.
- 원본 JSON은 고치지 않고 보관한다.

## 5. 채점 (매일, 수정주가 일봉 들어온 뒤)

종목별 값은 [AI 장전 계획 채점](AI_PREMARKET.md#채점)과 같다. 시가→종가(%), 비용 뺀 시가→종가는 `CLOSING_*` 비용을 쓰고, `SUSPECT`(갭 ±30% 초과)는 제외한다.

같은 날 함께 계산하는 바구니(동일 가중 시가→종가):

| 바구니 | 정의 |
| --- | --- |
| `POOL` | 명단 40종목 전체 (SUSPECT·NO_DATA 제외) |
| `AI_A` | A등급 |
| `AI_AVOID` | AVOID 등급 |
| `POOL_EX_AVOID` | 명단에서 AVOID를 뺀 나머지 |
| `RANDOM` | 명단에서 `AI_A`와 같은 개수를 무작위로 뽑음. 씨앗값 = 날짜 YYYYMMDD 정수 |
| `RULE` | 명단에서 전일 거래대금 20일 배수 상위, `AI_A`와 같은 개수 |
| `AI_TOP_CONF` | A·B 중 confidence 상위, `AI_A`와 같은 개수 (참고) |

## 6. 판정 (사전 등록)

- **채점일:** A등급이 1개 이상이고 채점이 끝난(COMPLETE 종목이 있는) 날. 처음 **40개 채점일**에 판정한다. 그 뒤 날짜는 판정을 바꾸지 않는다.
- **고르기 PASS:** 둘 다 만족해야 한다.
  - 일별 초과(`AI_A` − `POOL`)의 40일 평균 > 0
  - 초과가 양수인 날이 22일 이상(55%)
- **수익 PASS:** 고르기 PASS이면서 `AI_A`의 비용 뺀 시가→종가 40일 평균 > 0.
- **걸러내기 PASS:** AVOID가 1개 이상인 처음 40일에서 (`AI_AVOID` − `POOL`) 평균 < 0이고, 음수인 날이 22일 이상.
- **함께 보는 값(판정에 넣지 않음):**
  - `AI_A` − `RULE`, `AI_A` − `RANDOM`
  - 채점표 항목별 등급과 성과의 관계
  - 재실행 등급 일치율, 외부 정보 사용 종목
  - 날짜 블록 재표본 신뢰구간(판정 시점에 audit에서 계산)
- **FAIL이면** 그 기능(고르기 또는 걸러내기)은 실시간 감시·가상 매수에 연결하지 않고 결과를 기록한다. 판정 기준은 결과를 보고 바꾸지 않는다.

## 7. 이후 단계 (판정 뒤)

- 고르기 또는 걸러내기가 PASS인 것만 [2단계 실시간 감시](AI_PREMARKET_PHASE2.md)에 연결한다. AI의 `entry.type`과 `exit`를 고정 규칙(P·E1·E2)과 같은 날 비교 기록한다. 이 연결 규칙과 판정 기준은 그때 따로 사전 등록한다.
- OpenAI API 자동 호출, KIS 조건검색 출처 추가는 수동 기록이 안정된 뒤 검토한다. API 자동화는 비용이 들고 종목코드·시세 자료를 외부로 보낸다. 개인정보는 보내지 않는다.

## 한계

- 시가→종가는 실제 진입 시점과 다르다. 고르기·걸러내기 능력만 본다.
- 40일은 하루 0.3~0.5%p 수준의 차이를 겨우 구분하는 크기다. PASS는 "실시간 연결을 해 볼 만하다"는 뜻이지 수익 검증이 아니다.
- 변동성 명단 종목은 하루 움직임이 커서 날마다 차이가 크게 흔들린다.
- 사람이 매일 장 시작 전에 붙여넣어야 한다. 빠진 날은 기록이 없다.
- 공시는 접수일만 있어 장중 공시와 장 마감 후 공시를 구분하지 못한다.
- ChatGPT가 카드 밖에서 검색한 정보는 시각을 확인하기 어렵다(따로 표시해 나눠 본다).
