# 15:00 마감추천 전략 P5 시간순 OOS 검증

## 구현 범위

- 공식 `FORWARD` 실행 중 익일 관측이 완료된 현재 계산 버전 표본만 사용한다.
- 추천일을 시간순으로 정렬해 앞 70%를 개발 구간, 뒤 30%를 검증 구간으로 나눈다.
- 같은 추천일의 표본은 두 구간에 나뉘지 않는다.
- 추천점수 중앙값과 Feature 중앙값은 개발 구간에서만 계산한다.
- 개발 구간에서 정한 경계를 검증 구간에 그대로 적용해 목표 도달률과 평균 종가 수익률을 비교한다.

## 검증 Feature

- 추천점수
- VWAP 이격률
- 당일 고가 거리
- 체결강도
- 회전율

Feature 결과는 인과관계나 매수 확률이 아니라 구간별 관측 통계다. Feature 값이 없는 표본은 해당
Feature 비교에서 제외되며 다른 값으로 대체하지 않는다.

## 표본 상태

- 개발 구간 20건 이상, 검증 구간 10건 이상이면 `READY`로 표시한다.
- 그보다 적으면 `INSUFFICIENT_SAMPLE`로 표시하고 전략 채택 근거로 사용하지 않는다.
- 이 기준은 통계적 유의성을 자동 보장하지 않는다. 최소한의 화면 비교 가능 기준이다.
- 수동 `REPLAY`, 진행 중 관측, 불완전 관측은 포함하지 않는다.

## 화면

고급 마감추천의 공식 전진 전략 검증 영역에 다음을 표시한다.

- 개발/검증 기간과 표본 수
- 각 구간 목표 도달률과 평균 종가 수익률
- 개발 구간 중앙값 이상/미만 그룹의 검증 구간 성과
- Feature별 검증 구간 상위·하위 성과

## 제한

- 현재 통계는 신호가격 기준 시장 관측이며 P4 모의 체결 순수익과 아직 결합하지 않는다.
- 여러 Feature를 동시에 시험한 선택 편향 보정과 Walk-Forward 반복 창은 포함하지 않는다.
- 검증 표본이 충분해진 뒤 사전에 고정한 채택 기준과 비용 차감 성과로 최종 판단해야 한다.
