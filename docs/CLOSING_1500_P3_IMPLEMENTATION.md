# 15:00 마감추천 전략 P3 데이터 시점 보강

## 구현 범위

- 15:00 이후 설정된 확정 유예시간을 넘겨 생성되거나 수정된 5분봉은 FORWARD 평가 입력에서 제외한다.
- 세션 내 임의의 과거 봉이 사후 백필됐다는 이유만으로 후보 전체를 제외하지 않는다.
- 탐지 직전 필수 연속 봉 또는 최신 상태 판정에 필요한 봉이 평가 시점 이후 들어온 경우에만
  `RECEIVED_AFTER_EVALUATION`으로 제외한다.
- 기존 `stock_candle.created_at`과 `updated_at`을 재사용하며 중복 시각 컬럼은 추가하지 않는다.

## 판정 원칙

1. 시장 데이터 범위는 `evaluatedAsOf`인 15:00을 넘지 않는다.
2. `created_at`과 `updated_at`은 5분봉 확정 유예시간(기본 10초) 안이어야 한다.
3. 탐지 직전부터 연속된 확정 5분봉만 커버리지로 인정한다.
4. 평가에 사용하지 않는 과거 구간의 늦은 백필은 해당 후보의 시점 정합성을 훼손하지 않는다.

## 검증

- 필수 연속 봉이 15:00 이후 수정되면 후보가 제외된다.
- 필수 연속 봉이 모두 15:00 전에 확정됐으면 후보가 통과한다.
- 평가와 무관한 과거 봉이 15:00 이후 백필돼도 `RECEIVED_AFTER_EVALUATION`이 추가되지 않는다.
- 14:55~15:00 실시간 봉이 워터마크 처리로 15:00 직후 저장돼도 입력으로 인정된다.

## 뉴스·공시 및 ML 보류

뉴스·공시 신호와 ML 예측 점수는 아직 추천 판정에 연결하지 않는다. 현재 프로젝트에는 다음 입력이 없다.

- 발표 시각과 최초 수신 시각을 함께 보존한 구조화 사건 데이터
- 정정·삭제 이력을 포함한 과거 사건 원본
- 비용을 반영한 공식 모의체결 표본과 독립 검증 구간
- 학습 설정, 데이터 버전, 실험 실패까지 보존하는 모델 실험 원장

이 입력 없이 기능을 켜면 미래 정보 누수와 과적합을 확인할 수 없다. 사건 원천을 선정하고 공식
FORWARD 표본이 독립 검증 가능한 수준으로 쌓인 뒤, 기존 규칙 점수를 기준선으로 유지한 별도 실험으로
추가한다. 실제 주문 연동은 이번 범위에 포함하지 않는다.
