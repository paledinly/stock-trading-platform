# 15:00 마감추천 전략 P4 공통 체결 백테스트

## 구현 범위

- 백테스트 매도 전략이 함께 사용하는 봉 기반 체결 계산기를 추가했다.
- 평가 완료 후 첫 5분봉 시가를 진입 기준으로 유지한다.
- 익일 목표가·손절가, 갭 손절, 갭 목표, 시간 청산을 구분한다.
- 같은 5분봉에서 목표와 손절이 모두 관측되면 선후관계를 추정하지 않고 보수적으로 손절 처리한다.
- 매수·매도 수수료, 매도세, 양방향 슬리피지를 설정으로 분리했다.
- 총수익과 비용 차감 후 순수익을 별도로 집계한다.

## 설정

```properties
CLOSING_BUY_FEE_PERCENT=0
CLOSING_SELL_FEE_PERCENT=0
CLOSING_SELL_TAX_PERCENT=0
CLOSING_BUY_SLIPPAGE_PERCENT=0
CLOSING_SELL_SLIPPAGE_PERCENT=0
```

기본값은 모두 0이다. 실제 증권사·상품·시행일에 맞는 요율이 확인되지 않은 상태에서 임의 비용을
성과에 적용하지 않는다. 화면에서 비용 적용 여부를 함께 표시한다.

## 보수적 체결 규칙

1. 손절가 아래로 갭 하락하면 손절가가 아니라 해당 봉 시가로 청산한다.
2. 목표가 위로 갭 상승하면 해당 봉 시가를 청산 기준으로 사용한다.
3. 한 봉에서 목표·손절이 동시에 관측되면 손절 우선과 `ambiguous=true`를 기록한다.
4. 목표·손절이 없으면 마지막 확정 봉 종가로 시간 청산한다.
5. 5분봉만으로 부분체결, 호가잔량, 정확한 봉 내부 순서를 만들지 않는다.

## 검증

- 갭 손절 손실이 설정 손절률로 인위적으로 제한되지 않는다.
- 동일 봉 목표·손절은 손절 결과와 모호성 건수에 반영된다.
- 비용을 설정하면 순수익이 총수익보다 감소한다.
- 비용이 0이면 기존 총수익 결과와 호환된다.

실제 주문이나 매도는 실행하지 않으며, 이 단계는 저장된 5분봉을 이용한 모의 체결 계산만 수행한다.
