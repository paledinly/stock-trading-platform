KIS가 호출 한도 초과(`EGW00201`)를 HTTP 500으로 돌려줄 때 예외 이름만 남아 원인을 구분할 수 없던 문제 때문이며, HTTP 500 + `EGW00201`을 재시도할지는 기록을 본 뒤 정한다.
