# ADR-012: AI 장전 계획을 Forward로 기록하고, 새 기능 추가 동결을 푼다

Date: 2026-11-10

## 배경

- 마감 v9.1 판정(2026-11-09, 완료 465건/17거래일)은 BASELINE Net −0.769%, NEXT_OPEN −0.585%로 "중단"이었다. [FEATURES](../FEATURES.md#신규-기능-추가-규칙)의 "1차 체크포인트까지 새 수집·전략·화면 금지" 규칙은 이 판정을 기다리려고 둔 것이다.
- 사용자는 2026-11-10에 이 규칙을 풀고, ChatGPT가 장 시작 전 국내외 시장을 분석해 고른 종목을 프로그램에 넣어 검증하는 새 방향으로 진행하기로 했다. 진행 순서는 1단계(기록과 자동 채점) → 2단계(실시간 감시와 특정 시점 가상 매수) → 3단계(가상 포지션 관리) → 4단계(전략 비교)다.
- [ADR-011](ADR-011-NO-LLM-IN-RECOMMENDATION-PATH.md)은 추천 경로에 LLM을 넣지 않기로 했고, 다시 검토하는 조건으로 Forward 전용 평가, 모델·프롬프트 기록, 같은 날 병행 기록을 정했다.

## 결정

1. **새 기능 추가 동결을 푼다.** 새 수집·전략·화면은 이 ADR 이후 다시 추가할 수 있다. 운영 기본값을 바꾸는 임계값은 여전히 비교 검증이 필요하다(AGENTS.md).
2. **AI 장전 계획은 별도 기록으로만 둔다.** 운영 마감 추천의 점수·선정·구독·가상 진입에는 넣지 않는다. ADR-011의 "추천 경로에 LLM을 넣지 않는다"는 운영 마감 추천에 대해 그대로 유지한다.
3. **평가는 Forward로만 한다.** ADR-011의 재검토 조건을 이렇게 맞춘다.
   - 장 시작 전에 저장된 판만 집계한다. 지난 날짜 입력, 미래 시각의 분석·출처는 거부한다. 과거 날짜로 AI 판단을 재현하지 않는다.
   - 모델 이름·버전, 프롬프트 버전을 JSON 필수 칸으로 저장하고 원본 JSON을 고치지 않고 보관한다.
   - 같은 날 시장 평균(직전 20거래일 평균 거래대금 10억 원 이상, ETF·ETN 제외, 동일 가중)과 같은 시가→종가 기준으로 비교한다.
4. **1단계 통과 기준(미리 정함).** 집계 대상 판이 있는 TRADE 날 중 처음 20개 채점일에서 다음을 모두 만족하면 2단계(실시간 감시)를 만든다.
   - 그날 AI 매수 후보 평균 시가→종가 − 시장 평균의 20일 평균 > 0
   - 20일 중 12일 이상 시장 평균보다 나음
   미달이면 실시간 개발을 하지 않고 결과를 기록한다. 기준은 채점 결과를 보고 바꾸지 않는다.

## 이유

- AI 종목 선정은 과거 데이터로 공정하게 검증할 수 없어 Forward 기록이 유일한 검증 방법이다(ADR-011).
- 실시간 감시·신호 엔진은 수 주의 개발이 필요하다. 2026-10-13에 제거한 장중 추천은 비용보다 작은 기대 움직임, 추격 진입, 좁은 손절, 시장 국면 무시로 실패했다([실패 분석](../../audit/2026-10-13-intraday-failure-analysis/README.md)). 종목 선정에 우위가 있는지 먼저 싸게 확인한다.
- 1단계는 실시간 구독(41개 한도)과 KIS 호출을 쓰지 않고, DB의 일봉만 읽어 운영에 영향이 없다.

## 한계

- 시가→종가는 2단계의 실제 진입 시점과 다르다. 장 시작 전 정보로 고른 종목이 그날 시장보다 나은지만 본다.
- 20일은 검정력이 낮다. 통과는 "실시간 개발을 해 볼 만하다"는 뜻이지 수익성 검증이 아니다.
- 사람이 매일 장 시작 전에 붙여넣어야 한다. 빠진 날은 기록이 없다.
