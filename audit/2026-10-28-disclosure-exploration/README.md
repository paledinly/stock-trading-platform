# 공시 종류별 이후 성과 — DART 3년 (2026-10-28)

상태: **탐색. 판정 근거가 아니다.** 확증 표본(ADR-010) 기간의 가격은 쓰지 않았다(청산 10-22까지). 공시 분류, 진입·청산, 비교 기준, 기간, 남기는 기준은 실행 전에 [`disclosure.py`](disclosure.py) 머리말에 고정했다. 분류는 제목 빈도만 보고 정했고 성과는 보지 않았다. 출력: [`result.txt`](result.txt).

## 질문

특정 종류의 공시가 나온 뒤, 그 종목은 시장보다 나은가? 공시 목록에는 접수 날짜만 있고 시각은 없다. 그래서 **접수일 다음 거래일 시가**에 산다고 보수적으로 가정한다.

## 방법

- 공시: `dart_filing` 2023-10-04~2026-10-28(37.6만 건).
  - 정정·발행조건확정 등 `[`로 시작하는 제목은 뺐다.
  - 같은 종목·종류·날짜는 1건으로 셌다.
- 종류 7개(제목 포함 문자열):

| 이름 | 제목 |
| --- | --- |
| 자기주식 취득 | 자기주식취득결정, 자기주식취득신탁계약체결결정 |
| 공급계약 | 단일판매ㆍ공급계약체결(해지 제외) |
| 잠정실적 | 영업(잠정)실적 |
| 유상증자 | 유상증자결정 |
| 무상증자 | 무상증자결정 |
| 전환사채 | 전환사채권발행결정 |
| 주식 소각 | 주식소각결정 |

- 대상: 보통주 중 진입 전 20일 평균 거래대금 10억 원 이상.
- 진입·청산: 다음 거래일 시가에 사고, 그날 종가(H1), 5거래일째 종가(H5), 20거래일째 종가(H20)에 판다. BASE 비용을 적용했다.
- 시장 비교: 같은 날 같은 방식(시가→종가)으로 산 유동성 종목 평균. 자격은 진입 전날 거래대금으로 정했다(미래 참조 방지).
- 신뢰구간: 진입일 단위 평균, 날짜 연속 묶음 재표본(블록 max(5, H)).
- 기간: 탐색 2023-11~2025-04, 확인 2025-05~2026-10-21.

## 해석 (탐색)

1. **자기주식 취득 결정이 가장 일관됐다.** 공시 다음 날 시가에 사면 그날, 5일, 20일 모두 같은 날 산 시장보다 나았다. 두 기간 모두 같았다. 회사가 실제로 시장에서 주식을 사들이는 수요와, 경영진이 주가가 낮다고 보는 신호로 설명된다. 학계 보고와도 같은 방향이다.
2. **다만 비용을 뺀 절대 수익(Net)은 아직 확실하지 않다.** H20 Net은 +0.57% / +1.52%였고 구간이 0을 포함한다. 시장 전체가 같은 기간 시가→종가로 약했던 탓에, 시장 대비 우위가 절대 수익으로는 작게 보인다.
3. **무상증자는 20일 기준 시장보다 크게 나았다**(+4~8%p). 하지만 건수가 기간당 60여 건뿐이다. 무상증자 테마로 단기 급등하는 사례가 섞여 있을 수 있다.
4. **공급계약, 잠정실적, 유상증자는 다음 날 장중에 시장보다 빠졌다.** 공시 직후 시가에 이미 반영(갭 상승)된 뒤 되돌림이 나타나는 모습이다. 따라 사는 것은 불리하다.
5. 공시 **내용**(계약 금액, 실적 수치, 취득 규모)을 보면 더 강한 구분이 가능할 수 있다. 지금은 제목만 썼다.

## 한계

- 공시 시각이 없어 다음 거래일 시가 진입만 가정했다. 장중 공시는 접수일에 이미 일부 반영됐을 수 있다.
- 제목만 썼다(금액·실적 내용 없음). 잠정실적은 좋은 실적과 나쁜 실적이 섞여 있다.
- 상장폐지 종목은 일봉이 없어 그 종목의 공시는 빠졌다(생존 편향).
- 자기주식 취득과 무상증자는 같은 회사가 여러 번 공시할 수 있다. 회사 단위로 독립적인 사건은 건수보다 적다.
