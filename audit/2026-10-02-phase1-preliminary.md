# Phase 1 저장 데이터 예비 점검

2026-10-02 오전(KST) 실행. 로컬 실행 서버 GET API와 프로젝트 DB의 읽기 전용 트랜잭션으로 점검했다. 수집 활성화, 재평가, 성과 갱신, 데이터 수정은 실행하지 않았다. 실시간 수집 중이므로 수치는 조회 시점 기준이다.

## 핵심 판정

## 기존 데이터 품질

- 10/1 확정 5분봉: 61종목 2,156건. 정규장 78개를 모두 가진 종목은 0개, 최대 76개. 구독 시작/종료 및 무체결 여부를 대조하지 않았으므로 이를 모두 수집 장애로 단정하지 않는다.
- 10/1 종목별 첫 봉과 마지막 봉 사이에 5분을 초과한 간격은 14종목에서 25회. 누락된 봉의 총 개수와는 다르다.
- 10/1 14:30 이상 15:00 미만: 29종목 모두 6개 봉 저장. 현재 created_at/updated_at이 15:00:10 이하인 봉이 6개인 종목은 13개, 4개 이상인 종목은 29개. 이후 수정된 행의 당시 원본은 이 검사로 복원할 수 없다.
- 9/28 이후 저장된 일봉·5분봉에서 고가/저가 및 시가/종가 범위 역전, 음수 거래량·거래대금은 0건. 원천 가격 정확성·누적값 일치까지 검증한 것은 아니다.
- 일봉은 127종목 모두 82~90개로 21개 이상이다. 그러나 최신 일봉 날짜는 9/28 1종목, 9/29 24종목, 9/30 65종목, 10/1 37종목이다. 총 개수 충족은 최근 거래일 연속성·평가 당시 가용성 충족과 다르다.

## 추천 및 익일 연결

- 10/1 run 45: 15:00:30 평가 시작, 15:00:34 완료, FORWARD, 당시 상한 1, 추천 1건.
- run 45에서 제주반도체·삼성전자·원익IPS·KODEX 코스닥150·현대모비스는 RECEIVED_AFTER_EVALUATION 사유로 분류됐다. 수신 지연과 사후 정정/재저장 중 어느 원인인지 별도 확인이 필요하다.
- run 46은 15:18 FORWARD. run 47/48은 15:29 REPLAY로 구분돼 있다. run 48은 변경된 상한 5 아래 3건을 선정했다. 같은 날 여러 실행은 서로 독립적인 거래일 표본이 아니다.
- run 45의 KODEX 미국나스닥100 성과는 다음 거래일 10/2로 연결됐으며 09:15까지 관측, IN_PROGRESS, missingIntervals=[]였다. 하루 완료 성과가 아니다.
- 해당 기록의 virtualEntryAt/virtualEntryPrice/netReturnRate는 null, costStatus=NOT_EVALUATED. 익일 가격 관측 연결은 있으나 가상 체결·비용 반영 성과 완료는 확인되지 않았다.

## 다음 작업

1. 신규 Trajectory 수집과 지수 수집의 활성 설정을 적용할 작업을 별도로 진행한다. 기존 실시간 구독·랭킹 경로가 실제 동작하는지도 함께 확인한다.
2. 활성화 이후 1분 Feature와 context의 저장을 먼저 확인하고 장 후반 Snapshot까지 추적한다. 과거 결측을 5분봉으로 역생성하지 않는다.
3. 지연/정정 제외 5종목의 봉 저장 시각과 수집/보정 경로를 분석한다. 제외 기준을 바로 완화하지 않는다.
4. 실제 평가 대상 종목의 일봉 최신성과 연속성을 확인한다.
5. 익일 가격 관측과 가상 진입·비용 성과 연결을 분리 점검한다.

신규 Feature의 수치 재계산 일치, 순위 변화, 지수 최신성, Snapshot 미래 정보 누수 및 신규 오전 outcome은 표본이 없어 검증 대기다. 본 점검은 전략 수익성 검증이 아니다.
