# 5거래일 전략 비교 — 실행 전 고정 (2026-11-09)

사용자 요청: 운영 DB의 현재 수집 범위·품질을 직접 조회하고 새로운 5거래일 규칙을 비교한다. 운영 DB는 REPEATABLE READ / READ ONLY로만 접근한다. 원자료 캐시는 로컬 `data/`에 두며 커밋하지 않는다.

## 해석과 범위

- 기존 연구에서 가격 데이터 전 기간을 이미 탐색했다. 아래 시간순 확인 구간은 이 실험에서의 확인이며, 처음 보는 독립 OOS나 Forward가 아니다. 수급의 사용 완료 시험 구간과 재무 연구의 미사용 시험 구간은 재탐색하지 않는다.
- 일봉만으로 가능한 **전 거래일까지 정보 → d 종가 진입 → d+5 시장 거래일 종가 청산**을 비교한다. 15:15에도 알 수 있는 전일 정보로 신호를 만들지만, 종가 동시호가 체결을 가정하는 별도 연구다. 현행 15:20 이전 가상 진입의 성과로 표시하지 않는다.
- 현재 수집 완료된 날짜까지만 읽고 당일(2026-11-09)은 제외한다. 미래 수정주가·현재 종목 분류·사후 수신 이력의 한계를 명시한다.
- 거래일은 저장된 공식 달력이 있으면 그 값을 우선한다. 과거 공식 달력 미수집 구간에는 시장 전체 500종목 이상 거래된 날짜를 **연구용 세션 대용치**로 사용하고 그 수를 보고한다. 이 대용치는 ClosingTradingCalendar의 공식 운영 달력을 대체하지 않는다. 종목별 행을 5개 세는 방식은 쓰지 않는다.

## 공통 대상·거래·위험

- 보통주(기존 share/static_ids 규칙), 상장폐지 목록과 가격 포함. 20거래일 연속 유효 가격·거래대금, 60거래일 가격 이력, 직전 20일 평균 거래대금 >=10억 원. 입력일 이전 기업행사 비정상 점프 이후 60세션은 재개될 때까지 제외.
- 당일 종가/거래대금/수익률로 순위를 정하지 않는다. 가격 신호는 모두 전일로 shift한다.
- 각 규칙 일별 상위 최대 5종목. 신호 강도가 같으면 종목 id 순. 후보가 없거나 체결 불가능하면 현금. 매일 자금 1/5 슬롯을 새 코호트에 배정하고 5일 보유, 코호트 내 최대 5개에 같은 비중. 동일 종목의 다른 날 신호는 별도 코호트로 계산한다. 미사용 종목 슬롯은 현금.
- BASE 매수 0.095%, 매도 0.295%; HIGH 매수 0.165%, 매도 0.365%. 세율의 현재 사실이 아닌 기존 연구와 비교하기 위한 고정 비용 가정이다.
- 종가 +29% 이상 또는 거래량/가격 결측이면 미체결(후순위로 대체하지 않음). 이는 동시호가 체결가능성의 근사이며 매수호가 대기·용량을 증명하지 않는다.
- 예정 청산일에 가격이 없으면 매도 성공으로 처리하지 않는다. 예정일까지 마지막 유효가격에 50% 손실을 가정해 평가하고 0%/100% 손실 민감도를 함께 계산한다. 실제 정지 포지션은 계속 자금이 묶이므로 가상 계좌 성과는 스트레스 추정이며 실제 체결 원장이 아니다.
- 보유 중 ±31% 초과 가격 점프는 품질 불확실 거래로 표시한다(폐지 종목 마지막 10개 거래 행의 음수 점프는 실제 손실로 유지). 해당 거래는 버려 생존 편향을 만들지 않고 **원래 수익 대신 -50%**, 0%/-100% 민감도. 결과가 이 처리에 의존하면 채택하지 않는다.

## 사전 고정 비교안 (10개 + 기준선)

모든 조건은 전 거래일 기준. p는 같은 날 공통 대상 내 백분위 순위다.

| 이름 | 조건 | 순위(큰 값 우선) |
|---|---|---|
| MOM20 | 없음 | 20일 수익률 |
| REV5 | 없음 | -5일 수익률 |
| LOWVOL | 없음 | -20일 일간 수익률 표준편차 |
| GAP20 | 없음 | 최근 20일 시가 갭 양수 비율 |
| VALUE_SURGE | 전일 수익률 >0 | 전일 거래대금 / 직전 20일 평균 |
| TREND_PULLBACK | 20일 수익률 >0, 5일 수익률 <0 | -5일 수익률 |
| QUIET_TREND | 20일 수익률 >0 | -20일 변동성 |
| BALANCED | 20일 수익률 >0 | (p(-변동성)+p(갭 양수 비율)+p(-5일 수익률))/3 |
| BUYBACK | 직전 시장 세션 이후~전일까지 자기주식 취득/신탁계약 최초 공시 | 20일 평균 거래대금 |
| BUYBACK_QUIET | BUYBACK, 변동성 <= 공통 대상 중앙값 | 20일 평균 거래대금 |

기준선: 같은 공통 대상 전체 동일비중(신호 존재 효과 비교), 유동성 상위 5종목(소수 종목 비교), 현금(절대 수익). 공시 없는 날은 공시 전략 현금. 신호 발생일만 본 거래 평균과 모든 거래일 자금 기준 결과를 구분한다.

## 평가

- 탐색: 2018-04~2022-12, 확인 A: 2023~2024, 확인 B: 2025~마지막 완결 세션. 기간 경계를 넘는 보유는 포함하지 않는다. 결과를 본 뒤 임계값·방향·후보 개수 변경하지 않는다.
- 5일 거래 평균 Net·중앙값·승률·하위 5% 평균 손실, 같은 날짜 같은 대상 대비 초과, 블록 부트스트랩 95% 구간(20세션, 5,000회, seed 20261109), 연도별 성과.
- 일별 평가손익으로 자금 1/5 코호트 계좌의 누적 수익·최대낙폭을 추정한다. 동일 날짜 집단·보유 겹침을 무시한 거래 수 기준 신뢰구간은 쓰지 않는다.
- **연구 후보**: 탐색과 두 확인 구간에서 BASE/HIGH 평균 Net >0, 확인 구간에서 초과 >0, 확인 구간 BASE 평균 Net와 초과의 95% 하한 >0. 10개 규칙을 비교했다는 점을 보고하고 확인 구간의 다중검정(Holm 10개)도 확인한다. 최소 100회 체결·30신호일/구간. 이 기준에 미달하면 우승자를 만들지 않는다.
- 후보 간에는 확인 구간 평균 수익뿐 아니라 MDD, 비용 민감도, 연도별 부호, 이상값·정지 처리 민감도를 보고 우선순위를 판단한다. 미통과 규칙은 매수 추천으로 승격하지 않는다.

실행 전 이 파일을 작성했다. Git 커밋 기반의 독립 사전등록이라고 주장하지 않는다. 기존 운영 전략·설정·봉인된 재무 연구는 변경하지 않는다.
