# 요일·달력·대형주 탐색 — "언제, 어떤 크기의 종목을 사야 하룻밤이 나은가" (2026-10-27)

상태: **탐색. 판정 근거가 아니다.** 확증 표본(ADR-010)과 무관하다. 묶음, 결과, 기간, 남기는 기준은 실행 전에 [`calendar_size.py`](calendar_size.py) 머리말에 고정했다. 출력: [`result.txt`](result.txt).

## 질문

1. (B1) 진입 요일이나 주말·휴일을 끼고 들고 가는지에 따라 하룻밤 성과가 다른가?
2. (B2) 옵션 만기일, 만기 전날, 월말, 월초에 진입하면 다른가?
3. (C1) 대형·고유동 종목의 하룻밤 성과가 지금의 강세 후보(정밀 후보 근사)보다 나은가?

## 방법

- 기본 후보군 U1(정밀 후보 근사): 그날 거래대금 상위 100 중 +3% 이상.
- 결과: 종가 진입, 다음 날 시가 청산(NEXT_OPEN) 순수익, ADR-008 BASE 비용. 날짜 단위 평균.
- B1/B2: 해당 날짜들의 U1 평균과 나머지 날짜들의 U1 평균 차이(날짜 재표본 10,000회, 95% 구간). 만기일은 매월 둘째 목요일(휴장이면 직전 거래일)이다. 어느 기간이든 해당 날짜가 3일 미만이면 생략했다.
- C1: 대형 근사 L1 = 직전 20일 평균 거래대금 상위 50(등락 무관). L2 = L1 중 그날 +3% 이상. 같은 날 U1과의 차이(짝 비교).
- 기간: 탐색 03-18~07-31(74일), 확인 08-01~10-21(53일). 남기는 기준: 두 기간 부호가 같고 탐색 구간이 0을 포함하지 않음.

## 해석 (탐색)

1. 요일·주말 효과는 이 기간에 보이지 않았다. 수요일 진입이 두 기간 모두 약간 나빴고(−0.5%p 안팎), 금요일·연휴 앞이 약간 나았지만 구간이 넓어 우연과 구분되지 않는다.
2. 옵션 만기일은 탐색 기간에 구간이 0을 벗어났지만 날짜가 3일뿐이고 확인 기간에 뒤집혔다. 표본이 너무 작아 생긴 착시로 본다. 월말·월초도 날짜가 너무 적다. 이 질문은 1년치 이상 일봉이 쌓여야 다시 볼 수 있다.
3. 대형·고유동 종목에 하룻밤 프리미엄은 없었다. 등락과 무관한 대형주(L1)는 오히려 강세 후보보다 약간 낮았다(탐색 −0.36%p, 경계선). 대형주 중 강세 종목(L2)은 강세 후보와 같았다. "후보를 대형주로 바꾸면 낫다"는 근거가 없다.
4. 하룻밤 성과는 어떤 묶음을 고르는지보다 **기간(시장 국면)**에 더 크게 좌우됐다. U1 전체가 탐색 +0.53%에서 확인 −0.32%로 바뀌었고, 대형주도 같은 방향으로 움직였다.

## 한계

- 약 7개월, 2026년의 이례적 변동성 구간이다. 생존 편향이 있다.
- 만기일·월말 같은 달력 묶음은 기간마다 2~5일뿐이라 거의 판단할 수 없다. 지수 정기변경일은 날짜를 정확히 알 수 없어 넣지 않았다.
- 시가총액을 저장하지 않아 직전 20일 평균 거래대금을 대형주 근사로 썼다.
- 결과 비교가 12개다.
