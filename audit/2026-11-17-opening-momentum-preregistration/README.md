# 장초반 모멘텀 당일 매매 — 사전 등록 (2026-11-17)

상태: **판정 완료 (2026-11-17). 합격 0/12, 추격 차단 효과 있음.** 아래 [결과](#결과-2026-11-17). 사전 등록은 결과를 보기 전에 고정했다. 이 문서와 분석 스크립트([`opening.py`](opening.py))를 커밋한 뒤 처음 실행한다. 결과를 본 뒤 정의·기간·기준을 바꾸지 않는다. 바꿔야 하면 새 사전 등록으로 남긴다. 이 문서가 정하지 않은 세부(결측 처리, 동률, 이력 일수)는 스크립트 머리말에 실행 전에 고정했다.

## 질문

09:10에 알 수 있는 정보로 강한 종목을 골라 사면, 같은 날 안에 비용(왕복 약 0.39%)을 넘는 수익이 나는가? 추격 위험을 거르면 나아지는가?

외부 통합 개발 프롬프트(장초반 모멘텀 엔진, Entry Quality·Chase Risk 엔진)를 만들지 판단하기 위한 시험이다. 장중 돌파 추천은 2026-10-13에 실패했고([실패 분석](../2026-10-13-intraday-failure-analysis/README.md)), 15:15 장중 흐름 요소는 2026-11-03에 남은 기준이 없었다([장중 흐름 사전 등록](../2026-10-29-intraday-pattern-preregistration/README.md)). 이번 질문은 장 시작 직후 진입·당일 청산이라 그 둘과 다르다.

## 데이터와 대상

- 데이터: KIS 과거 분봉으로 재현한 5분봉(`intraday_research_bar`, 2025-10-30 ~ 2026-11-16, 하루 약 1,000~1,700종목). 읽기 전용이다.
- 대상(날 d, 종목 i). 모두 장 시작 전에 정해지는 조건이다.
  1. 보통주: 6자리 코드가 0으로 끝나고 Q·F로 시작하지 않으며, 이름에 '스팩'이 없고, ETF·ETN이 아니다(종목 플래그는 현재 값).
  2. 전날 거래대금(전날 5분봉 거래대금 합) 10억 원 이상. 수집 명단의 "당일 10억 원 이상" 조건은 장 마감 뒤 정보라 쓰지 않는다.
  3. 전날 종가(15:25 시작 봉 종가), 당일 09:00·09:05 봉이 있다. 최근 20거래일 이력이 있다(스크립트 머리말).
  4. |갭| ≤ 30%. 넘으면 액면분할 등으로 본다.
  5. 특수 장 시간인 날 제외: 2025-11-13, 2026-01-02.

## 09:10 지표 (09:00·09:05 봉만 사용)

| 이름 | 정의 |
| --- | --- |
| GAP | 시가 / 전일 종가 − 1 |
| RET10 | P(09:05 봉 종가) / 전일 종가 − 1 |
| VWAP10 | 두 봉 거래대금 합 / 거래량 합 |
| VALUE10 | 두 봉 거래대금 합 |

| OR_HIGH / OR_LOW | 09:00~09:10 고가 / 저가 |

## 전략 4개

공통 조건: RET10 ≥ +2%, P > VWAP10, P > 시가, RVOL10 ≥ 2. 하루 최대 5종목, 같은 금액. 진입가 ≥ 전일 종가 × 1.29이면 살 수 없다고 보고 제외한다.

| S1 모멘텀 | 없음 | 09:10 봉 시가 | RVOL10 상위 5 |
| S2 모멘텀 + 추격 차단 | GAP ≤ +5%, RET10 ≤ +10%, LAST5 ≤ +3% | 09:10 봉 시가 | RVOL10 상위 5 |

## 비교 기준

같은 날 대상 전체를 09:10 봉 시가에 사서 같은 청산을 적용한 평균(CTRL). 초과 = 그날 전략 평균 − 그날 CTRL. S3·S4도 같은 CTRL과 비교한다.

## 합격 기준 (전략 × 청산 12조합마다)

1. 하루 평균 Net(거래한 날의 종목 평균을 날짜로 평균)이 탐색·확인 모두 > 0
2. 탐색 95% 구간 하한 > 0 (연속 5일 묶음 재표본 10,000회, seed 20261117)
3. CTRL 대비 초과가 두 기간 모두 > 0
4. 확인 기간 플러스인 날 비율 ≥ 50%
5. 두 기간 각각 거래 100건 이상, 거래일 40일 이상

- 합격 조합이 있어도 운영에 바로 쓰지 않는다. 12개 비교라 우연일 수 있으므로 장초반 그림자 수집과 Forward 확인으로 넘어간다.
- 추격 차단 효과: S2 − S1(두 전략 모두 거래한 날의 차이)이 두 기간 모두 > 0이고 탐색 구간 하한 > 0이면 "효과 있음". 청산별로 본다.
- 하나도 합격하지 못하면 프롬프트의 Phase 3~6(장초반 엔진·추격 위험·통합 신호·계좌 위험)은 만들지 않는다.

## 해석

1. 5분봉 기준 장초반 매수·당일 청산은 이 기간 비용을 넘지 못했다. 프롬프트의 Phase 3~6(장초반 엔진·추격 위험·통합 신호·계좌 위험)은 등록한 규칙대로 만들지 않는다.
2. "추격하면 손해"는 다시 확인됐다(2026-10-13 실패 분석과 같은 방향). 다른 전략을 만들 때 쓰는 제외 조건 후보이지 그 자체가 수익 전략은 아니다.
3. 탐색에서만 좋았던 S3·S4는 기간 의존(2025-12 ~ 2026-04 상승장)으로 본다. 결과를 본 뒤 이 둘을 고쳐 다시 시험하려면 새 사전 등록과 새 데이터(2026-11-17 이후)가 필요하다.

한계: 5분봉 시가 체결 가정, 현재 종목 플래그, 2026-11-16은 수집이 일부(210종목)만 끝난 상태였다(추가 관측에만 영향).
