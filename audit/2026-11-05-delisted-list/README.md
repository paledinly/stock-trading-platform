# 상장폐지 종목 목록 (KRX KIND, 2026-11-05)

## 왜

`stock` 표와 그 위의 모든 연구 데이터(일봉, 수급, 분봉)에는 **지금 상장된 종목만** 있다. 그래서 2018년 이후를 쓰는 연구는 상장폐지 종목이 통째로 빠진 생존 편향을 가진다. 특히 [수급 단기 보유 연구](../2026-11-05-investor-flow-horizons/README.md)의 통과 칸은 "외국인·기관이 많이 판 종목"을 사는 쪽이라, 뒤에 폐지된 종목이 빠지면 실제보다 좋아 보일 수 있다.

## 받은 것

[kind_delisted_2017-2026.csv](kind_delisted_2017-2026.csv): [KRX KIND 상장폐지현황](https://kind.krx.co.kr/investwarn/delcompany.do?method=searchDelCompanyMain)의 엑셀 내려받기(공개 자료)를 시장별(유가증권 1, 코스닥 2, 코넥스 6)로 받아 합쳤다. 기간은 폐지일 2017-01-01 ~ 2026-11-05다.

| 구분 | 건수 |
| --- | --- |
| 전체 | 640 |
| 유가증권 / 코스닥 / 코넥스 | 102 / 375 / 163 |
| 유가증권·코스닥 중 시장 이전(코드가 계속 거래됨) | 14 |
| 유가증권·코스닥 중 스팩 | 170 |
| **등록 대상**(유가증권·코스닥, 이전·스팩 제외) | **293** |

등록 대상 293건을 사유로 대략 나누면(제목 문자열 기준, 연구에서 다시 정의한다):

| 분류 | 건수 | 예 |
| --- | --- | --- |
| 부실(감사의견 거절, 상장폐지 결정, 해산·파산, 자본잠식, 시가총액 미달 등) | 약 214 | 감사의견 거절, 기업의 계속성 … 상장폐지기준 해당 |
| 합병·완전자회사화 | 66 | 피흡수합병, 지주회사의 완전자회사화 |
| 신청에 의한 폐지 | 13 | |

부실 폐지(해산 포함)는 해마다 약 10~40건이다(2019년 적고 2025·2026년 많음).

## KIS 응답 확인 (2026-11-05)

- 2020-07-02에 폐지된 134780을 기준일 2020-01-15로 조회했다(`GET /api/v1/market-data/investor-history/probe`, 호출 1회). 2019-12-02 ~ 2020-01-15의 30거래일이 왔다. 그때 이미 거래정지 중이라 거래량 0, 가격 고정이었다.
- 응답에는 시가·고가·저가·종가(원), 거래량, 거래대금(원), 투자자별 순매수 수량·금액(백만 원)이 있다. 거래대금 단위는 삼성전자 2023-04-18 응답(9,669억 원)으로 확인했다.
- 그래서 폐지 종목도 `investor_daily_flow`와 같은 TR로 가격과 수급을 함께 받을 수 있다.

## 등록과 수집

백엔드 V45(`delisted_stock`, `delisted_daily_history`)에 넣는다. 의미는 [DATABASE](../../docs/DATABASE.md#delisted_stock--delisted_daily_history-v45-연구용)에 있다.

```
python register.py            # 293건을 POST /api/v1/market-data/delisted-history/stocks
curl -X POST http://localhost:8080/api/v1/market-data/delisted-history/backfill
curl http://localhost:8080/api/v1/market-data/delisted-history/status
```

## 알려진 한계

- 가격은 **원주가**다. 보유 기간 안에 액면분할·병합·무상증자가 있으면 수익률이 틀어진다. 연구에서 하루 ±30%(가격제한폭)를 넘는 변화가 있는 구간을 따로 다뤄야 한다.
- 폐지 직전 정리매매 기간의 가격이 응답에 있는지는 수집 뒤 확인한다.
- 2017-01 이전에 폐지된 종목은 목록에 없다. 연구 기간(2018~)에는 영향이 없다.
- 같은 회사가 다른 코드로 다시 상장한 경우는 따로 맞추지 않았다.
