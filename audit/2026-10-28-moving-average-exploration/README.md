# 마감 점수의 일봉 이동평균 요소 검증 — 3년 일봉 (2026-10-28)

상태: **탐색. 판정 근거가 아니다.** 확증 표본(ADR-010)과 무관하다(청산일은 2026-10-22까지). 요소 정의, 기대 방향, 결과, 기간, 남기는 기준은 실행 전에 [`moving_average.py`](moving_average.py) 머리말에 고정했다. 출력: [`result.txt`](result.txt).

## 질문

마감 추천 점수와 관문은 일봉 이동평균 요소를 쓴다.

- 관문: '일봉 추세 약함', '20일선 대비 과열'
- 가점: 정배열 +8, 20일선 상승 +5, 종가 20일선 위 +4
- 감점: 추세 약화, 과열

이 요소들이 강세 후보의 다음 날 성과를 실제로 가르는가? 점수 전체는 과거로 재현할 수 없지만, 일봉 요소는 3년 데이터로 운영과 같은 정의로 계산할 수 있다.

## 방법

- 후보: 그날 거래대금 상위 100(보통주) 중 +3% 이상 +29.5% 미만. 상한가 부근 마감은 잠겨서 살 수 없으므로 뺐다([급등 종목 분해](../2026-10-28-volatility-exploration/README.md)).
- 이동평균: 운영(`DailyMovingAverageService`)과 같이 **전날까지의 일봉**으로 계산했다. 과열 관문의 신호 가격은 당일 종가로 대신했다.
- 결과: 종가 진입, 다음 날 시가 청산(NEXT_OPEN)과 공식 +3%/−2% 규칙의 일봉 근사(BASELINE). ADR-008 BASE 비용을 적용했다.
- 비교: 같은 날 안에서 요소에 해당하는 후보와 해당하지 않는 후보의 차이. 날짜 연속 묶음 재표본(블록 5일, 10,000회).
- 기간: 탐색 2023-11-21~2025-04-30(351일, 11,879건), 확인 2025-05-01~2026-10-21(357일, 12,071건).

## 결과 (해당 − 비해당, %p)

| 요소 (점수에서의 쓰임) | 해당 비율 | NEXT_OPEN 탐색 / 확인 | BASELINE 탐색 / 확인 |
| --- | --- | --- | --- |
| 일봉 추세 통과 (관문) | 61~64% | +0.05 / −0.01 | +0.00 / −0.00 |
| 20일선 대비 12% 넘게 과열 (관문, 나쁠 것으로 기대) | 56~57% | +0.00 / −0.03 | −0.11 / −0.13 |
| 정배열 (+8) | 41~49% | −0.00 / −0.06 | −0.00 / −0.07 |
| 20일선 상승 (+5) | 68~71% | +0.04 / −0.08 | −0.04 / −0.06 |
| 종가 20일선 위 (+4) | 68~70% | +0.15 / +0.04 | +0.08 / +0.00 |
| 5일선 > 20일선 (감점 요소) | 65~68% | +0.01 / +0.06 | −0.01 / +0.01 |
| 120일선 위 (신규 후보) | 67~79% | −0.09 / −0.20 | −0.15 / −0.23 |

- **14개 비교가 모두 남기는 기준을 통과하지 못했다.** 차이는 대부분 ±0.1%p 안이다. 95% 구간도 대체로 ±0.2%p 안이라, 의미 있는 효과가 있었다면 잡혔을 만큼 표본이 충분하다.
- 과열 관문은 BASELINE에서 기대 방향(과열이 나쁨)으로 두 기간 모두 −0.1%p 남짓이었다. 그래도 구간이 0을 포함한다.
- 120일선 위는 오히려 약간 나빴다(두 기간 모두 음수, 구간은 0 포함).

## 해석 (탐색)

1. **일봉 이동평균 요소는 강세 후보의 다음 날 성과를 가르지 못했다.** 관문 2개와 가점·감점 요소 모두 3년, 약 2.4만 건에서 효과가 0 근처였다. 10-23 점수 보정 탐색(17일, 413건)에서 "점수와 관문이 순서를 가르지 못했다"는 결과와 맞는다.
2. 따라서 지금 점수의 일봉 부분(최대 +17점, 감점 최대 20점)과 두 관문은 **이 후보군에서는 근거가 없는 규칙**에 가깝다. 후보를 줄이는 효과만 있고, 그로 인한 성과 개선은 보이지 않는다.
3. 120일선 같은 장기선을 새로 넣을 근거도 없었다.
4. 일봉 이동평균이 쓸모없다는 일반적인 결론은 아니다. "당일 +3% 이상 강세 종목의 하룻밤 성과"라는 이 질문에서 정보가 없었다는 뜻이다.

## 한계

- 신호 가격 대신 당일 종가를 썼고, 진입도 종가로 가정했다(운영은 15:15 평가, 15:20 진입).
- 후보를 거래대금 상위 100 + 3% 이상으로 근사했다. 실제 정밀 후보는 스캐너 탐지와 장중 조건을 거친다.
- 상장폐지 종목이 없다(생존 편향). 하룻밤 성과라 영향은 작을 것으로 본다.
- 장중 이동평균(5분봉 5·20·60봉), VWAP, 체결강도 요소는 검증하지 못했다(과거 데이터 없음).
