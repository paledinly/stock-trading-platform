# 장중 수신 원장(intraday_input) 보관 — 2026-10-13

장중 추천 제거에 따라 `intraday_input`(DB 12GB, Supabase 포함 디스크 8GB 초과)을 테이블에서 비우기 전에 로컬로 보관했다.

- 도구: [ExportIntradayInput.java](ExportIntradayInput.java). 읽기 전용 트랜잭션으로 세션별 gzip JSONL을 만든다. 각 줄은 `id, sessionDate, stockCode, receivedAt, evaluatedAt, payload(원본 JSON)`이다.
- 위치: 저장소 루트 `backup/intraday-input/` (Git 제외). 세션별 `intraday_input_<날짜>.jsonl.gz`와 `manifest.tsv`(세션, 파일 행 수, 내보낼 때 DB 행 수, 최소·최대 id, SHA-256).
- 결과: 8세션 9,346,586행, 압축 938MB.

- 검증: 모든 파일을 압축 해제해 줄 수를 다시 세고, SHA-256이 manifest와 같음을 확인했다.
- 백업은 이 PC 한 곳에만 있다. 장기 보관이 필요하면 다른 저장장치에 복사한다.
- 재생에 쓰려면 각 줄의 `payload`를 `IntradayModel.Input`으로 읽던 기존 코드(커밋 `b0c874f` 이전 기준)를 사용한다. 장중 모듈은 제거됐으므로 해당 커밋을 체크아웃해야 한다.
